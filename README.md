# Lord Sai Investment & Share Market Academy Website

## Run locally

This is a static HTML/CSS/JavaScript website. Start a local server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/index.html` in a browser.

To directly review Mutual Fund mode, open:

`http://localhost:8000/home.html?mode=mutual-fund`
