Automation Admin Settings

Change the User ID you sign in with. The account, role and permissions stay the same; Main Admin credentials are not affected.

4–20 characters: letters, numbers, dot, underscore or hyphen. Use it (or the account email) at the next login.
Change Password

Changing the password logs this account out everywhere; sign in again with the new password.

8–72 characters with at least one letter and one number.
Student ID Series

Student IDs are always LSA/YYYY/NNNN: LSA is fixed, YYYY is the current calendar year (updates automatically each year), and only the owner can change the next four-digit serial. Existing Student IDs are never altered, and a number already in use can never be reissued.

Website Instructions

Automation Admin — every action you can do is listed below (not only the 12 menu tabs). Type what you want in the search box (example: “I want to give discount” or “reset ebook password”) and follow the numbered steps.

No matching topic. Try: add student, discount, record payment, receipt, attendance, ebook password, fee reminder, archive, delete, report.

1 Use the Dashboard

Where: Left menu → Dashboard

  1. Open Dashboard.
  2. Read summary cards (students, fees, attention items).
  3. Use quick buttons: Add Student, Record Payment, Generate Receipt, Mark Attendance, Search Student, Export Report.
  4. Filter the student list by batch or payment status.
  5. Click a student to open their profile, or use View / Pay / Edit on a row.

2 Search any student (top bar)

Where: Search box in the top header

  1. Click the header search box.
  2. Type Student ID, name, mobile or email.
  3. Click the matching result to open that student’s profile.

3 Add a new student (admission)

Where: Students → Add Student (or Dashboard quick button)

  1. Click Add Student.
  2. Fill required fields: Full name, Date, Address, Contact No., E-mail ID, Aadhaar, Course, Batch.
  3. Fill other admission details now or later (education, employment, trading experience, etc.).
  4. Check Student ID preview: LSA/YYYY/NNNN (LSA fixed, year = current year).
  5. Click Save. The Student ID is assigned automatically.

4 Change next Student ID serial (owner only)

Where: Add Student form → Change next serial (owner) · or Settings → Student ID Series

  1. Open Add Student (or Settings).
  2. Click Change next serial (owner).
  3. See prefix LSA/current-year/ (not editable).
  4. Enter the next four-digit number (must be higher than any serial already used this year).
  5. Click Set serial / Update Series.

5 Find and filter students

Where: Students

  1. Open Students.
  2. Type in Search (name, ID, mobile, email, batch).
  3. Optionally filter Batch, Course, Payment status, Admission Year, Status (Active / Archived / All).
  4. Use pager at the bottom if there are many rows.

6 Export / print the students list

Where: Students or Dashboard student table → Print / PDF / Excel

  1. Apply the filters you want first (export uses what is on screen).
  2. Click Print, PDF or Excel.
  3. Save or print the file.

7 Open a student profile

Where: Students → View · or search result

  1. Find the student and click View (or the name).
  2. Use tabs: Overview, Admission, Fees, Ebook Login, Payments, Receipts, Attendance, Course, Documents, Activity.
  3. Use top buttons: Edit, Discount, Record Payment, Latest Receipt, Mark Attendance, Archive, Delete.

8 Edit student details

Where: Student profile → Edit · or Students list → Edit

  1. Open the student.
  2. Click Edit.
  3. Change the fields you need (Student ID stays locked).
  4. Save.

9 Give, change or remove a discount

Where: Student profile → Discount · or Fees tab → Give discount

  1. Open the student profile.
  2. Click Discount (or Fees tab → Give discount).
  3. Choose which installment the discount applies at.
  4. Enter amount in ₹ or as %, and a reason for office records.
  5. Save. Fee after discount updates; later receipts show it.
  6. To change/remove: use Change / Remove on that discount line.

10 Record a fee payment

Where: Fees & Payments · student profile → Record Payment · Dashboard quick button

  1. Open Fees & Payments (or click Record Payment on the student).
  2. Search and select the student.
  3. Confirm fee / discount summary shown.
  4. Choose installment, amount, date, payment mode.
  5. Optional: transaction reference and notes.
  6. Click Save Payment & Generate Receipt.

11 Edit an existing payment

Where: Fees & Payments list · or student → Payments tab

  1. Find the payment row.
  2. Click Edit.
  3. Correct amount, mode, date, reference or notes.
  4. Save.

12 Check fees & installments for one student

Where: Student profile → Fees tab

  1. Open the student.
  2. Open the Fees tab.
  3. See course fee, discount, paid, balance and each installment status.
  4. Use Record next installment if still due.

13 Create / view Ebook Login

Where: Student profile → Ebook Login tab

  1. Record at least the first installment (ebook login is made after first payment).
  2. Open the student → Ebook Login.
  3. If status is READY, click Create ebook login.
  4. If NEEDS EMAIL, Edit the student and add an email first.
  5. When active, see User ID and password (until the student changes it).

14 Share ebook login details

Where: Student → Ebook Login

  1. Open Ebook Login.
  2. Click Copy login details to paste somewhere.
  3. Or Send on WhatsApp (needs mobile) — press Send in WhatsApp.
  4. Or Email login details (when password is on file).
  5. Or Print a paper copy for the student.

15 Reset ebook password

Where: Student → Ebook Login → Reset password

  1. Open Ebook Login.
  2. Click Reset password.
  3. Confirm. A new password is shown to the office.
  4. Share it with the student (WhatsApp / Email / Copy).
  5. Click Refresh if the student later changes password themselves — the new password appears here.

16 Reset ebook device binding

Where: Student → Ebook Login → Reset device

  1. Open Ebook Login.
  2. Click Reset device if the student changed phone / browser and cannot sign in.
  3. Ask them to log in again on the new device.

17 Block or unblock ebook access

Where: Student → Ebook Login → Block / Unblock ebook

  1. Open Ebook Login.
  2. Click Block ebook to stop access (student sees a blocked message).
  3. Click Unblock ebook to restore access.

18 Archive or restore a student

Where: Student profile → Archive / Restore

  1. Open the student.
  2. Click Archive to hide from Active lists (records stay).
  3. To bring back: set Status filter to Archived, open student, click Restore.

19 Delete a student permanently

Where: Student profile → Delete

  1. Open the student.
  2. Click Delete.
  3. Read the warning (payments, receipts, attendance, messages will be removed).
  4. Type the Student ID exactly to confirm.
  5. Confirm delete. This cannot be undone.

20 Find students with pending fees

Where: Pending Fees

  1. Open Pending Fees.
  2. Read the balance summary cards.
  3. Search or filter by batch, course, paid-so-far status.
  4. Highest balances appear first.
  5. Open the student or record payment from there.

21 Send a fee reminder

Where: Pending Fees → WhatsApp / Email on a row

  1. Open Pending Fees.
  2. Find the student.
  3. Click WhatsApp — chat opens with reminder text; press Send there.
  4. Or click Email and confirm to send the reminder email now.
  5. Check Message History if you need proof it was sent.

22 Export pending fees list

Where: Pending Fees → Print / PDF / Excel

  1. Apply filters.
  2. Click Print, PDF or Excel.

23 Open and preview a receipt

Where: Receipts · student → Receipts · Latest Receipt button

  1. Open Receipts (or student Receipts tab).
  2. Search by receipt no / student; optional date range.
  3. Click Open / select the row.
  4. Preview appears on the right.

24 Print, PDF or email a receipt

Where: Receipts → preview actions

  1. Select a receipt so preview loads.
  2. Click Print, Download PDF, or Email.
  3. Email sends the receipt PDF to the student’s email on file.

25 Share payment receipt (Email + WhatsApp picture)

Where: Email & WhatsApp → Payment Receipt card · or Communication row → Receipt

  1. Open Email & WhatsApp.
  2. In Payment Receipt, search and select the student.
  3. Select the payment receipt.
  4. One click emails the PDF and opens WhatsApp with a picture ready.
  5. In WhatsApp press Ctrl + V to paste the picture, then Send.

26 Mark attendance for a class

Where: Attendance · or student → Mark Attendance

  1. Open Attendance.
  2. Select Batch, Session Date, Session Type; optional Instructor.
  3. Click Open Attendance Sheet.
  4. Mark each student Present / Absent / Late (or Excused if shown).
  5. Optional: Mark All Present / Mark All Absent / Clear.
  6. Click Save Attendance.

27 Reopen a recent attendance session

Where: Attendance → Recent Sessions

  1. On Attendance, look at Recent Sessions (filter by batch if needed).
  2. Click Open on the session.
  3. Adjust marks and Save again.

28 Export attendance sessions

Where: Attendance → Recent Sessions → Print / PDF / Excel

  1. Filter batch if needed.
  2. Click Print, PDF or Excel.

29 Add or edit a batch

Where: Batches & Courses → Batches

  1. Open Batches & Courses.
  2. Click Add Batch (or Edit on a row).
  3. Enter name, schedule, start date, active status.
  4. Save. Assign students to this batch during admission / edit.

30 Add or edit an academy course

Where: Batches & Courses → Courses

  1. Open Batches & Courses.
  2. Click Add Course (or Edit).
  3. Enter name, default fee, duration, status.
  4. Save. Set / update price details under Course Price if needed.
These are classroom academy courses — not the website LMS courses in Master Admin.

31 Add a payment mode

Where: Batches & Courses → Payment Modes → Add

  1. Click Add under Payment Modes.
  2. Enter code and label (e.g. UPI, CASH).
  3. Save. It appears in Record Payment.

32 Add a session type

Where: Batches & Courses → Session Types → Add

  1. Click Add under Session Types.
  2. Enter code and label (e.g. CLASS).
  3. Save. It appears when marking attendance.

33 Set course price (for new admissions)

Where: Course Price

  1. Open Course Price.
  2. Find the course → Edit / set price.
  3. Enter total fee (and installment plan if the form shows slots).
  4. Save.
  5. Remember: already-admitted students keep their old fee — use Discount for one student.

34 Run a report

Where: Reports

  1. Open Reports.
  2. Choose report type: Student, Batch-wise, Fee Collection, Outstanding, Payment History, Receipts, Attendance, Low Attendance.
  3. Set filters: batch, course, mode, date range / quick range.
  4. For Low Attendance, set Threshold %.
  5. Click Run.

35 Export a report

Where: Reports → CSV / Print / PDF / Excel

  1. Run the report first.
  2. Click CSV, Print, PDF or Excel.

36 Send bulk Email / WhatsApp messages

Where: Email & WhatsApp → Automation table

  1. Open Email & WhatsApp.
  2. Filter students (search, batch, course, status).
  3. Tick students, or Select all (filtered), or use Send to all filtered.
  4. Choose Email and/or WhatsApp, write subject/message, attach if needed.
  5. Preview, confirm, send.
  6. For WhatsApp: each chat opens with text ready — you press Send.

37 Message one student from Communication

Where: Email & WhatsApp table → Email / WhatsApp buttons

  1. Find the student in the communication list.
  2. Click Email or WhatsApp on that row.
  3. Write and send (WhatsApp: press Send in the chat window).

38 Check Message History / retry failed

Where: Message History

  1. Open Message History.
  2. Filter by channel, status, dates; search recipient / subject / Student ID.
  3. Open a row for details / error.
  4. Retry if a failed action offers retry.
  5. Export with Print / PDF / Excel if needed.

39 Change Automation Admin User ID

Where: Settings

  1. Open Settings.
  2. Enter current User ID, new User ID, current password.
  3. Submit. Use the new User ID next login.

40 Change Automation Admin password

Where: Settings → Change Password

  1. Enter current password, new password, confirm.
  2. Submit — this account logs out everywhere.
  3. Sign in again. Main Admin is not affected.

41 Update Student ID series in Settings

Where: Settings → Student ID Series

  1. See Current Next Student ID and Highest Existing ID.
  2. Enter New Next Number (greater than highest existing this year).
  3. Click Update Series.

42 Logout

Where: Left menu Logout · or Settings → Logout

  1. Click Logout.
  2. You return to the Automation Admin login page.

43 Export payment history

Where: Fees & Payments → Payments list → Print / PDF / Excel

  1. Filter by batch, mode, from/to dates.
  2. Refresh if needed.
  3. Click Print, PDF or Excel.

44 Export receipts list

Where: Receipts → Print / PDF / Excel

  1. Filter/search receipts.
  2. Click Print, PDF or Excel.

45 See one student’s attendance history

Where: Student profile → Attendance tab

  1. Open the student.
  2. Open the Attendance tab.
  3. Review past sessions and percentage.

46 See student activity timeline

Where: Student profile → Activity tab

  1. Open the student.
  2. Open Activity.
  3. Read payments, admission and other office events for that student.
